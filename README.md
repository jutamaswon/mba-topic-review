# mba-topic-review 🎓🔥

Skill "อาจารย์สาย MBA เฟียสๆ" — วิจารณ์ (roast) และยกระดับ**หัวข้อวิจัยระดับปริญญาโท (MBA)** พร้อมสร้าง**แบบสอบถามเต็มรูปแบบ + Google Form อัตโนมัติ**

ตัวนี้คือเวอร์ชัน **ป.โท** — งานระดับปริญญาเอก (DBA/PhD) ใช้ repo คู่กัน: [dba-topic-review](https://github.com/jutamaswon/dba-topic-review)

## ทำอะไรได้

### PHASE 1 — THE ROAST & REFINE (วิจารณ์หัวข้อ)
ส่งไอเดียดิบเข้ามา → ได้ 3 ส่วน:
1. 🔍 **การประเมินไอเดียตั้งต้น** — วิจารณ์เฟียสตาม "กฎเหล็ก 4 ประการ" (ระบุแบรนด์ชัด / เก็บ n=400 ได้จริง / ทฤษฎีแข็งแรง / แก้ปัญหาธุรกิจจริง)
2. 🧠 **ทฤษฎีและกรอบแนวคิดที่แนะนำ** — 2-3 ทฤษฎี + ระบุ IV/DV ชัดเจน
3. 💡 **4 ชื่อหัวข้อระดับ ป.โท** — จัดหมวดตามสายทฤษฎี (Tech / Consumer / Marketing / Sustainability) — ทุกชื่อมี "ในเขตกรุงเทพมหานครและปริมณฑล"

### PHASE 2 — QUESTIONNAIRE GENERATION (สร้างแบบสอบถาม)
ส่งหัวข้อที่ตกลงแล้ว + ขอแบบสอบถาม → ได้ 2 ไฟล์:
- `questionnaire.md` — แบบสอบถามเต็มสำหรับให้ผู้ทรงคุณวุฒิตรวจ (ทุกข้ออ้างทฤษฎีอ้างอิง)
- `generate_form.gs` — โค้ด Google Apps Script กดรันแล้วได้ Google Form สำเร็จรูปทันที

**โครงสร้างแบบสอบถาม:**
- Part 1 (a1-a10+): ประชากรศาสตร์ + พฤติกรรมเชิงลึก — a1 เพศ (ชาย/หญิง), a2 อายุแบบ Generations อิง พ.ศ. 2569 (Gen Z / Gen Y / Gen X / Baby Boomer), a3 สมรส, a4 การศึกษา, a5+ พฤติกรรมจำเพาะ (ความถี่ / ยอดใช้จ่าย / วัตถุประสงค์ / ผู้ตัดสินใจ / brand switching) เพื่อทำ cross-tabulation
- Part 2: ตัวแปรหลักแบบ Likert 5 ระดับ (labels มาตรฐานตายตัว) + blockquote ทฤษฎีอ้างอิงทุกข้อ

## กฎเหล็ก (ใช้กับทุก Phase)
- ❌ ห้าม 4Ps (Marketing Mix) — ล้าสมัยสำหรับระดับบัณฑิตศึกษา
- ❌ ห้ามหัวข้อกว้าง — ต้องระบุแบรนด์/แอป/บริการเดียวชัดเจน
- ✅ ทุกตัวเลือกต้องมีเลขนำหน้า ("1. ชาย", "2. หญิง")
- ✅ น้ำเสียง: ตรงไปตรงมา ไม่ต้องชม วิจารณ์เต็มที่

## วิธีใช้แบบ copy-paste (ไม่ต้องติดตั้งอะไร)
1. เปิด [`SKILL.md`](SKILL.md) → **copy เนื้อหาทั้งไฟล์**
2. ไปที่ ChatGPT / Claude / Gemini → วางเป็นข้อความแรกของบทสนทนา (หรือใส่ใน Custom Instructions)
3. พิมพ์ไอเดียหัวข้อ เช่น *"อยากศึกษาพฤติกรรมผู้บริโภค Grab"* → ได้ PHASE 1
4. เลือกชื่อที่ชอบ → พิมพ์ *"สร้างแบบสอบถามจากข้อที่ 2"* → ได้ PHASE 2

## วิธีรัน Google Apps Script (สร้าง Google Form)
1. ไปที่ <https://script.google.com> → **New project**
2. ลบโค้ดตัวอย่าง → วางเนื้อหา `generate_form.gs` ทั้งไฟล์
3. กด **Run (▷)** → ขอสิทธิ์ครั้งแรก → กด **Allow** ให้ครบ
4. ใน Execution log จะแสดง **ลิงก์ Google Form** ที่สร้างใหม่ → เปิดแก้ธีม/เปิดรับคำตอบได้เลย
5. หากจะสร้างฟอร์มชุดใหม่ซ้ำ: แก้ชื่อฟอร์มในบรรทัด `FormApp.create(...)` ก่อนรันรอบถัดไป
